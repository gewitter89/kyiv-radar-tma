# Київ Радар 1.21 — масштабований інвентар нерухомості

## Ціль

Не обмежуємося 3–5 квартирами. Приватний інжестор розрахований до 1 000 000 записів у одному пакеті (це технічна межа, а не кількість перевірених об'єктів): продаж, довгострокова й подобова оренда квартир, кімнат, будинків, офісів, комерції, складів, землі, паркінгів і новобудов по Україні.

**Важливо:** цей PR тільки створює інфраструктуру. Немає нових ліцензій, фідів чи прав на історичні 150 записів. Жоден новий об'єкт НЕ потрапляє у публічний каталог автоматично.

## Джерела, у порядку підключення

1. Агентства, забудовники, керуючі компанії: власні авторизовані JSONL/CSV/JSON-фіди з source ID, правами та умовами відкликання. Приймаємо пакетами, без ручного введення кожної квартири.
2. Офіційний DIM.RIA API: дозволяє шукати оголошення за операцією, категорією і регіоном. Потрібні API-ключ і допустимий сценарій використання, атрибуція джерела. У безкоштовному пакеті документація вказує 30 запитів/год та 1000/місяць.
3. OLX Partner API: потребує авторизації користувача; не є публічним API для збирання всієї бази чужих квартир.
4. Інші портали — тільки договір/офіційне API/фід, який дозволяє саме потрібний спосіб використання.

Джерела документації:
- https://developers.ria.com/products
- https://api-docs-v2.readthedocs.io/ru/latest/dom_ria/search.html
- https://api-docs-v2.readthedocs.io/ru/latest/dom_ria/index.html
- https://developer.olx.ua/ua/articles/partner-application-user
- https://www.agentiz.com/uk/partnership/aggregation/ua (приклад формату партнерських фідів на іншій платформі, не наш партнер)

## Private mass intake

Скрипт: scripts/market_inventory.py

- JSONL (для великих наборів), CSV і JSON.
- Строгі operation: rent/sale/daily_rent і property_type: apartment, room, house, townhouse, office, commercial, warehouse, land, garage, parking, new_build.
- Потрібна приватна атестація оператора: source_key, agreement_ref, valid_until, allowed_source_hosts, operator_rights_reviewed=true та metadata_display_permitted=true. Файл із підтвердженням має бути ПОЗА публічним репозиторієм. Запис true НЕ доводить наявності прав; відповідальна людина зобов'язана перевірити договір.
- Унікальний ключ source + external_id, ідемпотентні запуски, транзакційний відкат некоректного пакету, не більше мільйона записів і 250 МіБ на файл.
- Відкидаються поля фото, телефон, імена, описи, точні координати. У публічні JSON і API нічого не надходить.
- Повтори між джерелами за канонічним HTTPS URL або виданим партнером unit_key — лише кандидати, без автоматичного злиття.
- Повне оновлення вимагає дозволу full_snapshot_allowed=true. Не вважаємо об'єкт знятим через один пропуск. Після двох пропусків — possible_withdrawn до ручної перевірки. Величезне падіння обсягу джерела блокує пакет, щоб уникнути масового видалення через збій.
- Зміна ціни/даних у вже схваленому об'єкті переводить його в needs_review. Жодна дія інжестора не встановлює approved.

Приклад синтетичної атестації (НЕ реальне підтвердження прав):
    {
      "source_key":"agency_kyiv_a",
      "agreement_ref":"contract_2026_a",
      "operator_rights_reviewed":true,
      "metadata_display_permitted":true,
      "valid_until":"2027-01-01",
      "allowed_source_hosts":["example-agency.ua"],
      "full_snapshot_allowed":true
    }

Приклад однієї синтетичної JSONL стрічки:
    {"external_id":"A-001","source_url":"https://example-agency.ua/offer/A-001","operation":"rent","property_type":"apartment","city":"Київ","district":"Дарницький","price_uah":18000,"rooms":2,"area_m2":52}

Приклад запуску лише після реального дозволу та отримання фіда:
    python scripts/market_inventory.py --feed /secure/incoming/agency.jsonl --agreement /secure/grants/agency.json --database /secure/radar/inventory.sqlite --full-snapshot

Приватні батьківські директорії створює оператор перед запуском. Без full-snapshot відсутність лота в неповному фіді не вважається видаленням. Статистика CLI не містить персональних даних.

## Офіційний DIM.RIA discovery — IDs only

Скрипт: scripts/dim_ria_discovery.py

За замовчуванням він працює в режимі плану: **0 запитів до мережі**. Для запуску потрібні приватна угода з source_key=dim_ria, allowlist dom.ria.com, змінна середовища DIM_RIA_API_KEY, операторське підтвердження прав та явний прапорець --execute.

Приклад ПЛАНУ (коди продажу квартир за прикладом документації; інші категорії беруться з офіційних таблиць):
    python scripts/dim_ria_discovery.py --agreement /secure/grants/dim.json --database /secure/radar/dim.sqlite --category 1 --realty-type 2 --operation-type 1 --state-id 10 --city-id 10 --pages 3

Виклик з --execute виконує реальні офіційні запити. До 25 сторінок/запуск, локальний лічильник до 30/год і 1000/місяць, резервування запиту ДО звернення. На HTTP 429 безконтрольних повторів немає, ключі не пишуться в stdout. Локальний бюджет НЕ враховує інші застосунки з тим самим ключем, тому на production потрібен один спільний scheduler.

Зберігаємо тільки provider ID, first_seen та last_seen. **ID не є доказом права показувати оголошення, існування, статусу контакту чи права використовувати фото.**

## Після отримання перших легальних фідів

- Планувальник по всіх містах і типах, контроль квот/дельта-оновлень і зупинка джерела при відсутності дозволу.
- Приватна модерація прав, дубль-кандидатів, скарг, зняття з публікації й свіжості інформації.
- Обмежений публічний вихід тільки для дозволених об'єктів; приховані телефони залишаються поза GitHub.
- UI для оренди/продажу та всіх регіонів з пагінацією й фільтрами, із зазначеним джерелом.
- Метрики: унікальні чинні дозволені об'єкти, частка дублів, прострочення, успішні реальні контакти. Не показувати неіснуючі цифри «живих» квартир.

## Стоп-умови

Історичні 150 імпортованих карток поки не мають підтвердженої актуальності/контактів і прав на медіа. Цей PR не змінює production API, VPS, Caddy, Telegram-токен, роботу бота або публічний каталог. Платні API-пакети чи сторонні скрапери не купуються і не запускаються.
