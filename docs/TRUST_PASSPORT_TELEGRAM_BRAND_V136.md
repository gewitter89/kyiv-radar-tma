# Київ Радар v1.36 — довіра до оголошень і чиста назва Telegram

## Картка квартири
У модальному перегляді з'явився компактний паспорт даних. Він розділяє заявлені характеристики та факти, які мають окреме підтвердження. Джерело, кімнати, ціна, площа, поверх, доступність, власник, контакт і комісія мають свої пояснення. Суперечність кімнатності або поверху не приховується.

У паспорті немає фальшивого загального відсотка довіри чи «перевірено все». Джерело саме по собі не підтверджує власника або права повторної публікації. Дата перевірки доступності відображається лише для свіжої явної незалежної перевірки. Заявлені ціни, комісія та площа не отримують автоматичне підтвердження.

## Помилки і модерація
Паспорт повторно використовує /api/reports та вже наявну модерацію. Додано причину «Кількість кімнат відрізняється від джерела» та необов'язкове пояснення (до 500 символів). Текст не публікується й не зберігається в GitHub. При 5xx форма зберігається до повторної спроби.

Коли реальний API прибирає оголошення, відкрита стара картка та скарга закриваються замість того, щоб залишити попередній контакт або перейти на інше житло з таким самим numeric ID.

## Старе найменування Telegram
У публічних підказках та помилках прибрано технічний нік @prostov_shrink_bot та фрази «Відкрити бота». Використовується назва «Київ Радар» / «Відкрити у Telegram». Вебклієнт не повторює сирий текст помилки старого API. Серверна публічна 502 помилка також приведена до нового тексту.

**Увага:** фактична Telegram-адреса `t.me/prostov_shrink_bot` збережена для робочої авторизації; її без перевіреної заміни не можна видаляти або міняти. Заголовок, ім'я користувача та інші написи, які малює **сам Telegram**, не можна приховати CSS/JS нашого сайту. Для зміни видимого імені бота потрібне налаштування BotFather власником, окремо від релізу сайту.
