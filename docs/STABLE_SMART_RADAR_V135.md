# Київ Радар v1.35 — безпечне порівняння та збережений пошук

## Проблема
В избранном с версии v1.30 применяется устойчивый source+permalink, а прежний «Мій радар» продолжал хранить сравнения по numeric ID, сравнивать избранное с числовым ID и считать «новые» квартиры по временному номеру. Это может привести к подмене квартиры после обновления фида.

## Исправления
- Новое локальное хранилище kr_compare_keys_v2: {version:2,keys:[]} с использованием favoriteKey. Ключ принимается только при допустимой HTTPS-ссылке и однозначности source+URL в активном каталоге.
- Старые kr_compare_ids_v1 остаются только в карантине: без автоматического переноса или подстановки другой квартиры. Пользователь может отдельно удалить старые номера.
- Пропавший, отозванный, изменивший ссылку или дублирующийся объект отображается как «Збережене порівняння недоступне». Не происходит reassignment по numeric ID.
- Кнопка «Порівняти» из карточки принимает ID текущего видимого объекта, но в localStorage сохраняет только устойчивый ключ.
- В сохранённых поисках для базовой отметки используются knownKeys, а не knownIds. Старые сохранённые поиски не создают ложные «нові» до явного нажатия «Переглянуто».
- Фильтр «Обрані» совпадает со стабильным ключом; 3 комнаты означают ровно три, 4 — четыре, 5+ — пять и более; граница бюджета сохраняется точно.
- Сравнение открытого объекта обновляется после удаления/отзыва объекта сервером.

## Тесты
Playwright проверяет повторное использование numeric ID, изменение permalink, карантин старого localStorage, favorites-only saved search, дубли, отсутствие URL, legacy baseline, отзыв объекта в открытом сравнении, фильтры 4 и 5+, плюс Syntax check JS и общий CI.

## Границы
Сборка кумулятивна поверх v1.34 и v1.32. GitHub CI не подтверждает производство или актуальность квартир. Никакого скрапинга OLX, VPS-применения, смены Telegram-токена, платежей или публичного релиза. Перед выпуском требуется exact-head CI, резервное копирование с восстановлением, API+Pages smoke, ревью прав на источники и ручное E2E в Telegram iOS/Android. Нельзя одновременно сливать кумулятивные PR #54, #57 и этот PR.
