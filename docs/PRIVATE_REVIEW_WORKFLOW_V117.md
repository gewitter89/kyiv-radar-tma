# Київ Радар 1.17 — закрита черга перевірки оголошень

## Що вже є і чого ще немає

Реліз 1.16 дає **підказки для ручної перевірки**: можливі повтори одного джерела/фото, статистику походження і застереження для орендаря. Він не довів власність, актуальність, комісію чи законність передруку 150 імпортованих оголошень.

Реліз 1.17 готує **офлайн-чергу для модератора**. У ній немає телефонів, власників, адрес, фото, URL, приватних доказів чи персональних даних. Генератор не звертається до OLX, DOM.RIA, Telegram або VPS, не змінює каталог чи статус оголошень і не вмикає сповіщень.

## Як користуватися

На захищеній робочій машині, з робочої директорії репозиторію:

    python scripts/reviewer_queue.py --output /tmp/kyiv-radar-review-2026-11.json

- Вивід у новий файл **поза** публічним репозиторієм; права файлу 0600. Перезапис існуючого файлу заборонений.
- Зберігайте робочі рішення й докази в окремому приватному сховищі з обмеженим доступом і політикою видалення, а **не** в Issue, PR, GitHub Actions artifact або публічних JSON.
- Інтерфейс: listing_id, відома назва джерела, priority, possible_duplicate_ids, перелік checks, moderation_decision. За замовчуванням усі перевірки not_reviewed, рішення pending_manual_review.
- high_review означає пріоритет перевірки, **не** дубль/шахрайство. Результат генерації не можна імпортувати як доказ або як автоматичне approved.

## Операційний сценарій

1. **Права на використання.** Модератор перевіряє, чи маємо явний дозвіл/ліцензію від власника контенту/платформи на саме той спосіб показу тексту, фотографій і метаданих. URL у загальнодоступному інтернеті не є ліцензією.
2. **Реальна квартира.** За дозволеним каналом перевірити, чи пропозиція актуальна, адресу й точність координат, кількість кімнат та заявлені характеристики. Не використовувати слова «власник підтверджений», «0% комісії» або «в наявності», якщо для кожного твердження немає окремого доказу.
3. **Повтори.** Порівняти оригінальні джерела в дозволеному доступі, фото лише за належних прав, опис та факти. Два записи можуть представляти ту саму квартиру або різні пропозиції. Рішення ухвалює людина із журналом причини та можливістю виправити помилку.
4. **Контакт і згода.** Залучити 3–5 орендодавців, які добровільно подадуть власні оголошення і підтвердять право на фото. Заявки залишаються непублічними до модерації. Перевірка контакту **не означає** підтвердження права власності.
5. **Скарга / відкликання.** Дати орендодавцю й власнику прав зрозумілий шлях запросити виправлення, зняття оголошення та видалення фотографій. За відсутності прав / актуальності приховувати відповідну інформацію після рішення відповідального модератора.
6. **Справжній E2E.** На iPhone і Android у Telegram: форма власника → завантаження приватних фото → модерація → публічна картка → запит контакту → отримання його в приватному чаті → скарга/приховування. Без тестових номерів у відкритих звітах.
7. **Пілот.** Лише після цього 10–20 запрошених користувачів; фіксуємо реальні збій/результат без вигаданих переглядів і відгуків.

## Чіткі обмеження

- Жодного автоматичного скрапінгу, копіювання нових чужих фото, публічних PII або позначок «перевірено».
- Без автоматичного схвалення, видалення або злиття дублів за простим збігом фото/ціни.
- Без платної реклами, автоматичних повідомлень, платежів і неузгодженої зміни Telegram-токена.
- Не торкатися kyivpulse, Woodstoria й інших сервісів VPS.
- Веб- та API-деплой цього інструмента не потрібен; запуск на production до підтвердженого E2E не означає продуктову готовність.

## Критерії готовності

- 150/150 записів можуть бути поставлені в закриту чергу без PII; кандидатні дублікати мають пріоритет.
- Спроба записати звіт у репозиторій або перезаписати файл завершується помилкою.
- Жодна зміна відкритої бази, API, пошуку, контактів чи токена не відбувається.
- Для першої публічної групи є зафіксовані дозволи, результати модерації та успішний ручний тест контакту від реального орендодавця.
