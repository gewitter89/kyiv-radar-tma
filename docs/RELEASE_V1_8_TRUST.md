# Київ Радар 1.8 — достовірність оголошень і контроль якості

## Головне правило

Завдання сервісу — допомогти знайти квартиру в Києві та не вводити
орендаря в оману. Справжня наявність житла, право власності, комісія,
право публікувати фото і робота обладнання при відключеннях — це
окремі питання. Ні один пункт не підтверджується автоматично іншими.

На старті є 150 імпортованих оголошень, але жодне не має незалежного
підтвердження власника, комісії або актуальності в публічному каталозі.
Не називати їх перевіреними.

## Як модерувати

1. Перевірити оригінал, дату, умови, наявність житла, згоду на
   публікацію даних і фото, можливість контакту та фактичного перегляду.
2. Приватно зафіксувати доказ, дату, спосіб і відповідального модератора.
   Документи власника, номер, листування та посилання на приватні
   докази НЕ зберігати на GitHub Pages.
3. Оновити приватний реєстр, шлях до якого задає змінна середовища
   KYIV_RADAR_PRIVATE_REVIEW_PATH. Він лежить поза вебкоренем.
4. Для актуальності потрібні reviewer, evidence_ref, checked_at,
   available=true; дата ISO 8601 з часовим поясом, не старіша 14 днів.
   Для власності, контакту, комісії та локації — окремі підтвердження
   з confirmed=true, reviewer, evidence_ref, checked_at.
5. Оголошення, яке здали або зняли, позначити hidden, removed,
   withdrawn або archived. Відразу перевірити API, видачу контакту,
   а також синхронно прибрати його з публічного статичного каталогу
   data/deals.json та вбудованої копії в index.html. Інакше воно може
   залишитися видимим при недоступному API.
6. На кожну скаргу модератор має ухвалити рішення; скарга сама по
   собі не доводить правдивості твердження. Не стирати журнал безпеки.

Приватний приклад (дані вигадані, не означають фактичну перевірку):

    {
      "schema_version": 1,
      "listings": {
        "999999": {
          "state": "verified",
          "availability": {
            "available": true,
            "reviewer": "staff-1",
            "evidence_ref": "private-case-999999",
            "checked_at": "2026-11-17T09:00:00+00:00"
          }
        },
        "999998": {"state": "hidden"}
      }
    }

## Перевірки коду

- python scripts/audit_catalog.py --output artifacts/catalog-quality.json
- python -m pytest tests/test_listing_trust_v18.py tests/test_trust_experience_v18.py
- CI перевіряє незмінність приватних даних, зникнення прихованих
  пропозицій, часові межі, актуальність підписів, журнал скарг та
  повторну відправку після помилки.
- Щоденний монітор перевіряє відповідь API та публічну сторінку,
  але це НЕ тест підтвердження актуальності або доставки контактів.

## Вимоги перед production

- Резервна копія SQLite з WAL, фото, справжнього каталогу і конфігів.
- З'ясувати реальний шлях імпорту серверного модуля, встановити
  kyiv_radar_api.py та listing_trust.py разом, перевірити /api/health.
- Перевірити Caddy, маршрути, обмеження завантаження фото (Issue #8),
  а також сусідні сервіси на спільному VPS.
- Перевірити права на використання описів і фотографій джерел.
- Реальний iPhone та Android: пошук, фільтри, фото, порівняння,
  скарга, контакт через Telegram, обробка помилки.
- 10–20 реальних добровільних тестувальників, 0 невиправлених
  критичних помилок, жодних вигаданих оцінок/відгуків.
- Не починати масову рекламу, платні операції або автоматичні
  сповіщення до перевірки джерел, згоди користувачів і окремого
  погодження власника.

## Назва в Telegram

Назва Mini App «Київ Радар — Оренда 0%» вводить в оману:
комісія ще не підтверджена. Власнику слід змінити заголовок
через @BotFather на «Київ Радар» або «Київ Радар — оренда квартир».
Це зміна НАЗВИ, не перевипуск Telegram-токена.

## Безпека й редагування

Власник прямо наказав залишити старий токен без змін. Ризик
можливого попереднього розголошення відкритий в Issue #7.
Не викладати токени, номери, документи, приватні докази в GitHub.
Мова інтерфейсу — проста українська, без шуму, вигаданих
переваг, «нейромаркетингу» та помилкових бейджів довіри.
Технічне походження змін і справжні журнали перевірок не приховувати.
