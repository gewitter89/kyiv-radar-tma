# Київ Радар 1.24 — відкликання та строк дії прав на приватні фіди

Це **приватний gate інвентарю**, а не підключення живих агентств або дозвіл
публікувати нерухомість. Існуючі дані можуть бути неперевіреними за фактом
існування, власником, контактом і правом показувати медіа. Масової публікації немає.

## Проблема

Після імпорту пакета його контракт може закінчитися або партнер може відкликати
право використання. Не можна продовжувати вважати такий інвентар схваленим
тільки тому, що він колись мав review_status=approved.

## Реалізовано

- Таблиця `source_rights` прив'язує джерело до приватного `agreement_ref`,
  `valid_until`, `active|revoked`; приватний `source_rights_audit` фіксує
  registration, shortening і revocation без PII.
- При першому імпорті джерела права записуються у тій самій транзакції, що
  й пакет. Старі `approved` лоти такого джерела переводяться на `needs_review`.
- Повторний імпорт **не** може увімкнути відкликане джерело, підмінити договір
  або продовжити строк договору без окремого перегляду оператором.
  Скоротити строк дозволено (fail-closed).
- SQLite triggers забороняють проставити `approved`, якщо джерело відсутнє,
  відкликане або його строк дії завершився на поточну дату UTC. Це додатковий
  захист від помилкових ручних SQL змін, а не повний захист від DBA.
- `revoke` атомарно змінює стан джерела і скидає попередні `approved` лоти
  на `needs_review`, не видаляючи аудиторський слід.
- `assess` виводить приватний агрегований стан джерела і числа інвентарю;
  не робить публічний export, не називає лоти verified і не видає контактів.
- Без привілеїв на запис у приватну БД рішення не змінити.
  Майбутній public API має **самостійно** виконувати ці перевірки;
  сама таблиця source_rights не прибирає записи з іншої вже розгорнутої БД.

## Приклади (ЛИШЕ на приватній БД після реального дозволу)

Перевірити стан:
```bash
python scripts/source_rights.py assess \
  --database /secure/radar/inventory.sqlite \
  --source example_agency
```

Відкликати договір, якщо власник фіда вимагає припинити використання:
```bash
python scripts/source_rights.py revoke \
  --database /secure/radar/inventory.sqlite \
  --source example_agency \
  --reason partner_request
```

Дозволені причини: `partner_request`, `contract_expired`,
`compliance_hold`, `operator_hold`. Ніяких персональних подробиць
у логах. Повторне revoke ідемпотентне. Протилежної команди reactivate немає:
потрібен новий дозволений договір та окремий контрольований workflow.

## Поточні заборони

Не вмикати будь-які партнери тільки через цей код. Немає автоматичної
перепублікації чужих фото, телефонів, описів чи адрес. Не запускати це на VPS,
production DB або Telegram-боті без окремого узгодженого релізу. Не змінювати
старий токен. Історичні 150 записів залишаються неперевіреними.
